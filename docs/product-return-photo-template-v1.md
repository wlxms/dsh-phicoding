# 产品返图模板 v1

> **目标**：让看图的人相信「这个人已经买了、放在自己家里用着」，而不是「这个商品长什么样」。
> **适用**：桌面小物、自发光小家电、香薰、化妆镜这类「放上去就不会再动」的东西。
> **不适用**：需要手持、穿戴、正在动的商品（那是使用示范，不是返图）。

---

## 0 总原则

| # | 原则 | 含义 |
|---|---|---|
| 1 | **主体不做主角** | 不居中、不正对、允许被挡 20–30%、允许压边。商品看不全是**结果**，不是让步。 |
| 2 | **曝光只对一处正确** | 夜里就是那盏灯，白天就是窗边那块。AI 感的根源是「所有东西都恰到好处」。 |
| 3 | **每个物件都能正常使用且符合常识** | 空间要能走、抽屉要能拉、窗要能开、插座要能插、灯要照到人。 |

---

## 1 第 0 关 · 硬门槛（一条不过，不进入打分）

### 1.1 空间可用性

| # | 判据 | 反例 |
|---|---|---|
| 1 | 床头柜紧贴床头，与床垫面高差 ≤ 5cm | 柜子在床尾、在房间另一侧 |
| 2 | 抽屉/柜门前方净空 ≥ 深度 + 10cm | 柜子正对床，抽屉拉不开 |
| 3 | 窗前净空 ≥ 60cm | 床把窗堵死，关不了窗 |
| 4 | 窗帘下摆不被家具压住 | 床压在窗帘上 |
| 5 | 插座在柜面上方 60–70cm，或柜旁不被遮挡 | 插座被床头顶住 |
| 6 | 床至少一侧留 ≥ 50cm 下床；主走道 ≥ 60cm | 床两边都是墙 |
| 7 | 门/衣柜开启扇不压床、不压柜 | 衣柜门撞床 |

### 1.2 产品就位

| # | 判据 | 反例 |
|---|---|---|
| 8 | **朝向以使用者为参照**：朝床 / 朝枕头 / 朝房间 | 「斜 25 度」——这是以镜头为参照 |
| 9 | 光落在人身上，不落在墙上（刻意做氛围除外） | 灯板正对镜头，光全打在墙 |
| 10 | 底座全在台面内，离柜沿 ≥ 5cm，不压抽屉前沿 | 底座悬在柜沿，一碰就掉 |
| 11 | 电源线从底座后方出，朝插座一侧走，不横穿台面 | 线从台面正中拉过去 |
| 12 | 线长 ≥ 灯具到插座直线距离 × 1.3 | 灯离插座太远，线不够 |
| 13 | 躺下时看得见、起身不会碰到 | 摆在起身必经处 |

### 1.3 写法约束

| # | 判据 | 反例 |
|---|---|---|
| 14 | 家具关系用 **相机站位 + 平面图** 锁定 | 「床在窗旁，旁边有床头柜」——换视角就全错 |
| 15 | 产品朝向用 **人的位置** 描述 | 用相对镜头的角度描述 |

> **平面图写法示例**
> 相机在床的中段旁边、离床头约一米，朝床头方向看。床头软包靠右墙；
> 床头柜夹在床头与右墙之间，抽屉朝画面左前；窗在左墙，与床头墙成直角，
> 窗下留 60cm 过道；床尾在画面外。

## 2 第 1 关 · 配比打分（D / A / R）

### 2.1 D｜陈旧度（单件 0–1）

| D | 状态 |
|---|---|
| 0 | 出厂 / 崭新 |
| 0.3 | 用过但保持整洁 |
| 0.6 | 明显在用、开始旧 |
| 1.0 | 老 / 脏 / 起球 / 积灰 |

### 2.2 A｜随意度（单件 0–1 + 重复衰减）

「距离刻意摆放的距离」。类别：倒、开、缠线、散叠、压遮、撕、用剩、**不搭**。

同一类别第 n 次出现的权重：

~~~
n = 1  → +s
n = 2  → +0.5s
n = 3  → +0.25s
n ≥ 4  → −0.25s × (n−3)
~~~

- s 为该类强度（0–1）：盖子全开 0.9、半开 0.5、线缠成一团 0.8
- **第 4 次开始倒扣**：同一个「随意」重复太多次，读起来就是在安排随意
- **「不搭」是独立类别**：风格/年代/材质与周围冲突的廉价物（s=0.9）

### 2.3 R｜重复度

~~~
R = 1 − K / N      K = 类别数，N = 实例数
~~~

R=0 全部不同类别；R→1 同一个动作反复出现。

### 2.4 加权与阈值（**预注册，禁止事后调整**）

按元素像素占比 w_i 加权：

~~~
D̄   = Σ w_i · D_i
σ_D = √( Σ w_i · (D_i − D̄)² )
A   = Σ w_i · s_eff_i
~~~

| 指标 | v1 阈值 |
|---|---|
| D̄ | 0.25 – 0.50 |
| σ_D | ≥ 0.20 |
| A | 0.22 – 0.40 |
| R | ≤ 0.50 |

### 2.5 三层结构

| 层 | 面积占比 | 作用 | 硬要求 |
|---|---|---|---|
| 面 | ≥15%（墙/床/柜面/地面） | 定基调 | 至少一个面 D ≥ 0.40 |
| 件 | 3–15% | 承担 A 的主要来源 | ≥3 个不同类别，每类 1 次 |
| 碎 | <3% | 只补细节 | 不作为证据 |

**主体放在「件」层**：面积 5–15%，D ≤ 0.1，A = 0，清晰度最高。

### 2.6 六条结构性判据（不依赖阈值）

1. 遮住主体，这张图仍然是「某人的房间」
2. 画面里至少有一个「完全没有含义」的物件
3. 至少一处曝光是错的（过曝 / 死黑 / 闪光硬阴影 / 焦点跑偏）
4. 画框切掉了东西
5. 至少一对相邻物件 |ΔD| ≥ 0.50
6. 至少一个物件 |D − a| ≥ 0.40（新旧与随意不同步）

## 3 第 2 关 · 提示词骨架（八段）

~~~
1 谁、在什么时刻、用什么姿势拍
2 相机站位 + 平面图（锁住家具关系）
3 空间可用性（净空、插座、窗帘、抽屉）
4 材质与陈旧度（D 分布落点）
5 场景里的动作（A 预算，每类只写一次）
6 产品的摆放与朝向（按人的位置写，不按镜头）
7 光与曝光（只对一处正确）+ 摄影缺陷（焦段、噪点、歪 2–3°）
8 裁切残缺 + 负向 5–8 条
~~~

### 3.1 负向清单（这次验证过的）

- 拖鞋、单独一杯水、摊开的书、搁在书上的眼镜
- 正对镜头、居中、对称
- 「斜 X 度」这类相对镜头的描述
- 空墙 + 悬浮木架
- 墙面装饰三件套（照片墙 + 便签 + 挂钟）
- 台面无瑕疵、全图统一暖调
- 收藏品等距正立（收藏可以整齐，但要有薄灰）
- 为了暗示生活而放进去的任何东西

### 3.2 槽位（每次只换一个）

| 槽 | 取值 |
|---|---|
| 空间类型 | 出租屋 / 精装小公寓 / 合租单间 / 独居小户型 |
| 受众 | 女大学生 / 白领女性 / 情侣 / 中年夫妻 / 男生 |
| 拍摄时刻 | 刚拆封 / 用完还没收 / 躺床上 / 开闪光 / 白天 |
| 品类 | 桌面自发光小物（本模板默认） |

**受众不是标签，是语言**：女生房间与男生房间的织物、道具、墙面装饰是三套东西，不能共用。

## 4 第 3 关 · 后期（确定性，不靠模型）

1. **旋转 1.5–3°**，重裁：切掉柜角、切掉墙架、产品压边
2. **色散**：R/B 通道径向缩放 0.12–0.18%
3. **颗粒**：不均匀，暗部更重（σ ≈ 0.010–0.017）
4. **暗角**：0.20–0.40 径向衰减
5. **四角软化**：角部叠高斯模糊 1.5–2.5px
6. **压高光**：>0.90 柔化到 1.0，去掉假 HDR
7. **冷阴影 / 暖高光**分调

**必检**：刻字、手办的脸、底座结构、有没有新增黑边或撕裂。

---

## 5 第 4 关 · 验收

### 5.1 六问（任一不过就不交）

1. 遮住产品，这还是一张「某人的房间」吗？
2. 有没有至少一样毫无含义的东西？
3. 有没有一处曝光是错的？
4. 画框有没有切掉东西？
5. 相邻物件有没有互相遮挡、挤压？
6. 有没有哪样东西是「为了暗示生活」放进去的？有就删。

### 5.2 数值验收

按 2.4 阈值逐项打钩；**阈值必须在看图之前写下**，否则不算数。

## 6 附录 A · 算例

| 版本 | D̄ | σ_D | A | R | 判定 | 原因 |
|---|---|---|---|---|---|---|
| 白墙 + 悬浮架 + 干净台面 | 0.08 | 0.05 | 0.04 | — | ❌ | 跨度 1，样板间；靠碎件加 A 无效（面积权重太小） |
| 「加大生活感」批（手办打散、书歪、笔滚） | 0.65 | 0.10 | 0.05 | 0.83 | ❌ | 单一类别重复 6 次，A 转负；σ_D 不足 |
| 精致公寓 · 暗调版 v1 | 0.37 | 0.17 | 0.23 | 0.14 | ❌ | σ_D 不足；A 主要来自小件；审美全对，缺「不搭」 |
| 精致公寓 v2（+ 塑料盒 + 墙面胶印） | 0.46 | 0.20 | 0.29 | 0.20 | ⚠️ | 数值过；但暗调本身是审美选择，光仍是摆拍 |
| 最终版（平面图重排 + 灯朝床） | 0.42 | 0.20 | 0.28 | 0.20 | ✅ | 第 0 关 15 条全过 |

### 失败模式清单

| 现象 | 根因 | 修法 |
|---|---|---|
| 把房间从整洁改成混乱反而更假 | 全图 D 整体平移，跨度不足 | 拉跨度，不抬水位 |
| 加道具永远不管用 | 面积权重太小 | 改「面」层 |
| 桌角线条笔直、构图对称 | 没做后期旋转/重裁 | 第 3 关 |
| 「乱」被理解成更乱更脏 | 单一类别重复 | R ≤ 0.5，每类 1 次 |
| 商品看不全、字糊 | 正确朝向的必然代价 | 接受它 |

## 7 附录 B · 已知边界

1. **中文字还原不稳定**：实测 8 张里 1 张把中文刻字糊成错字。刻字重要时单独验证。
2. **编辑会引入破损**：换墙面元素时模型曾把左上角撕出一块纯黑，必须逐张查边角。
3. **无外部参考**：本机出网受限，拿不到真实房间照片比对，判断依赖经验。
4. **「旧」和「乱」会被放大**：灰尘做成土块、脏污做成发霉。所有痕迹都要给上限。
5. **待定**：A 的「面层贡献 ≥60%」判据按物体面积算会低估台面（台面的 A 由台上小件承担）。是否改为按「区域」计，未定 —— 改判据即改标准，需单独决议。
