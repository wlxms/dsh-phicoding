# 设计契约

## 三集：按"失效会怎样"分层

分三道跑，每道加一层条件，加进去的东西必须可见。

| 层 | 判据 | 归宿 |
| --- | --- | --- |
| **最简流程** | 去掉一切外部条件，最少要哪些元素才能达成目标 | 编排写死，主干本体 |
| **必要集** | 逐条问：**失效后流程能否完成，或能否在流程内自愈？** 不能 → 必要 | 主干不变量 |
| **质量集** | 其余。只登记，不论证 | 插槽 / 注册表 / 写死 |

**「不可逆」要读成「无法完成，或无法在流程内自愈」。** 断网可重试 → 仍是必要（缺它流程完不成）；帧率低但流程照样完成 → 质量。

**第四类：主干里的非不变量步骤。** 有些元素失败了可自愈（因此**不是**必要项），但主干确实执行它并据此分支——例如开写之前的空间预检。遇到这种，明确标注「**在主干里执行，但记在质量集**」，不要含糊过去。三集不覆盖它，而它真实存在。

**必要集可以被设计压缩。** 判据用来测量必要集，设计用来压缩它。换一个更强的不变量，某些必要项会直接消失——例如把「断点续传日志」换成「内容寻址暂存 + 幂等 diff」，日志就不需要了。压缩的判据：**不要制造第二个真相来源。**

## 两轴：决定缝的形状

两层都问，缺一层就各错一半。

|  | 实现替换性：低 | 实现替换性：高 |
| --- | --- | --- |
| **成员拓展性：低** | **写死的本体** —— 编排与顺序 | **主干内插槽** —— 成员固定、实现会换 |
| **成员拓展性：高** | **增量型注册表** —— 主干不知道数量 | **主干外扩展点** —— 最外层的需求集中区 |

- **成员拓展性**看"会不会新增成员"，驱动源是需求的变化率。
- **实现替换性**看"实现会不会换"，驱动源是方案空间（有多少种都站得住的做法）。
- 两轴独立：它们压成一条"拓展性高/低"的标尺就会把两种形状混为一类。

## 三种接口来源（外加一种要删的）

- **被迫的**（必要性）—— 核心必须与外部交流的接触点。你无法拥有它，只能声明它。契约要窄、形状要稳。
- **扇出型**（很多实现）—— 正当的扩展点。**扇出看实现。**
- **扇入型**（很多调用者）—— 形状**冻结**。**扇入看调用点。** 在这里放变化点是灾难。
- **变异驱动**（投机）—— 为将来可能换实现而抽。数量应为零，除非已有 ≥2 个具名变体。

复用性只证明接口「够通用」，**不证明它「该存在」**。这是两个断言。

## 对象层三判据

1. **边界** — 这份契约的消费者是谁？同一份模型服务同一群消费者 = 一个边界。
2. **归属** — 这个词属于谁的世界？参数合法，仅当调用者对它有一个独立于实现的意见。测试：问调用者「你想要吗」；能立刻回答 → 他的决定；反问「多少合适」 → 是旋钮。
3. **形态** — 表达的是**结果**还是**步骤**？步骤词几乎必然泄漏：`clearFile`（先清空，会带进新的失败模式）应改成 `Replace`（结果，且不变量写进了名字里）。

**一个方法 = 一个核心流程。** 不改变编排的差异 → 参数；改变编排的差异 → 新方法。
两个方向的违规撞同一条律：同流程拆成多方法 → 变体名长在方法集合里；不同流程塞进一个参数 → `switch (mode)` 长在实现里。

## 递归：目标树

一个单元如果有自己的目标、自己的失效模式、自己的可选项，**它自己就是一个功能**：递归进去，给它自己的三集。

- **终止条件**：问不出「它的最简流程是什么」就停。问不出来 = 它的目标就是它唯一做的事 = 叶子。
- **封装规则**：递归进去是为了设计它，**递归出来只带走它的接口**。下层的必要集不自动成为上层的必要集。
- 所以不存在全局必要集，存在的是一棵目标树；同一个元素在父树是质量集、在自己的子树可以是必要集。

## 设计卡模板

```markdown
## 设计卡 · 第 N 轮
- 级别：实现级 | 设计级 —— <一句话依据>
- 核心价值（一句话 + 现实约束的**量**）：…
- 用例集（取**最吃力**的那个，不是最省事的）：…
- 假设（边界）：1. 假设 … 成立   明确不做：…
- 最简流程：…
- 必要集（逐条注明"失效是否可逆"）：…
- 质量集：…
- 变化轴（成员拓展 × 实现替换）：…
- 缝的形状：注册表 / 主干内插槽 / 主干外扩展点 / 写死
- 接口来源：被迫 / 扇出 / 扇入 / 投机
- 变体 #2 的预言：… ，预期主干改动 **0** 行
- 主干改动归类（若必须动主干）：同轴新变体 / 正交新轴 / 用例集扩张
- 验收标准：A1 …；A2 …
- 阶梯用例：| 档 | 用例 | 输入 | 期望 | 它强制新增的实现/容错 |  （L1 起）
```

卡写不下来的那一条，就是你还没想清楚的那一条。
